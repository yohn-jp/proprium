# `proprium.knowledge`

This directory contains the recovered pure Story Knowledge domain algorithms. The source is ported from Scriptorium `95a66c2c985a66bc2d535392dcc450d8c9df18d5`; `SnapshotId` is localized to this plugin package so it has no Scriptorium runtime dependency. The pinned Arcadia Loom source `edc033c2c9466274a334299dadfa426661d957d9` remains recovery evidence for the world-state UI and persistence workflow.

The domain kernel covers relationship graphs, relation gaps/co-occurrence, backlinks and appearances, scene context, series overlays, thread lifecycle, Japanese relative-time analysis, objective state folds and reader-disclosure analysis. The tests preserve the pinned legacy algorithm cases. They do not establish signed artifact delivery, Host v2 action/UI integration, persistence, or browser acceptance. Those require the shared Host and registry implementation and the KNO-A01–A19/R01–R14 browser gates.
