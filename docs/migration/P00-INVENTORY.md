## Source persistence facts

`ledger.json` records the source storage model and per-registration source readers/writers. `ProjectStore.reload()` reads project YAML/Markdown and rebuilds the configured index at `<dataDir>/index/<project>/index.sqlite` (legacy fallback `<projectRoot>/.arcadia/index.sqlite`). Several source readers and writers omit the configured `indexDir` and call `getIndexPath(rootDir)`/`openIndex(rootDir)`, so they target `<projectRoot>/.arcadia/index.sqlite`; both DB paths can exist with different rows. SQLite schemas contain both rebuildable projections and persistent proposal workflow records. `scene_state_events` is rule-derived from entities/links and regenerated on configured-index rebuild. `reader_knowledge_events` is derived from current disclosures and refreshed by the reader-model request helper; the current reader-model loader reads `scene_state_events`, not `reader_knowledge_events`. Persistent provisional workflow rows live in `zukan_suggestions` and `state_proposals`; proposal statuses must be preserved, and approvals also write canonical YAML. Contradiction dismissals are separately stored in `meta/contradiction-dismissals.jsonl`. Do not classify either DB as disposable from its filename or treat derived event projections as author decision history. The ledger lists source evidence and explicitly leaves migration dispositions/proofs pending.

## MCP source mutation paths

The machine-readable R48 row records source line evidence for both transports. HTTP MCP `create_scene` directly creates/reorders scene files and commits them; HTTP MCP `lint_manuscript` with `fix=true` directly rewrites a manuscript. Stdio MCP `create_scene` submits a ChangeSet proposal, but scene-scoped `lint_manuscript` with `fix=true` calls the persistent API lint handler. Target `suggest_rewrite` maps the saved-scene sentence index through snapshot-bound NLP spans to compute-only `assistant.rewrite`, while `get_diagnostics` invokes the full `diagnostics.scene` aggregate. Current MCP integration tests cover both transports, but this ledger does not claim final-head acceptance.
